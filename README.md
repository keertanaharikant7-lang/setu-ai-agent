# SetuAI

## Overview
SetuAI is a voice-first AI agent designed to help users interact with legacy mobile applications that do not provide APIs.

The system enables rural citizens, farmers, elderly users, and regional language speakers to access digital services using simple voice commands.

## Problem Statement
Many public-service and regional applications are difficult to navigate and lack API support. This creates barriers for non-technical users.

## Solution
SetuAI uses:
- Voice input
- Screen understanding
- UI navigation
- AI planning
- Secure user confirmation

to complete tasks on behalf of users.

## Key Features
- Multilingual voice support
- Zero-API operation
- Intelligent screen analysis
- Autonomous app navigation
- Human-in-the-loop security

## Technology Stack
- Whisper
- Bhashini API
- Llama 3.1
- EasyOCR
- Android Accessibility Services
- Python
- ADB
