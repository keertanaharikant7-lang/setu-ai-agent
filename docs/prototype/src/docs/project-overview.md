# SetuAI

## Problem
Many legacy government, banking, and public-service applications do not provide APIs and are difficult for rural and elderly users to navigate.

## Solution
SetuAI is a voice-first AI agent that understands user requests, analyzes mobile app screens, and performs actions directly through the user interface.

## Key Features
- Multilingual voice support
- Zero-API operation
- Intelligent UI navigation
- Human-in-the-loop security

## Technology Stack
- Whisper
- Bhashini
- Llama 3.1
- EasyOCR
- Android Accessibility Services
- Python
